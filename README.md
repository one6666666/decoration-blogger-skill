# 装修博主助手

基于小辉家装课程笔记提炼的装修博主内容创作 Skill，帮助用户从0到1打造爆款装修内容，实现变现。

## Skill 内容

- **选题策划**：5大类选题模板（错误类、矛盾类、带货类、体验类、知识类）
- **爆款元素**：8大爆款元素分析（成本、人群、奇葩、踩坑、荷尔蒙、憧憬、美好、冲突）
- **脚本撰写**：脚本结构公式与文案技巧
- **拍摄指导**：拍摄要点、画面技巧、内容技巧
- **人设打造**：人设要素与四要素法则
- **引流变现**：引流工具与团购带货准备
- **对标参考**：全屋智能、装修变装、省钱家装等账号类型

## 使用方式

### 方式一：WorkBuddy Skill 安装

将 `SKILL.md` 和 `_meta.json` 复制到 `~/.workbuddy/skills/装修博主助手/` 目录即可。

### 方式二：独立使用

直接参考 `SKILL.md` 中的方法论进行内容创作。

## 文件结构

```
装修博主助手/
├── SKILL.md       # Skill 主文件（完整方法论）
├── _meta.json     # Skill 元数据
└── README.md      # 说明文档
```
